Import câu hỏi từ CSV

Định dạng CSV:
Cột: topic_id, type, prompt, answer, opt1, opt2, opt3, opt4, extra

type = mcq / fill / arrange / phonics / listen / tf / odd
opt1–opt4: các lựa chọn (opt1 = đáp án đúng hoặc để trống nếu answer đã đủ)
extra: hint/gợi ý (tùy chọn)

Ví dụ:
animals,mcq,"con mèo là gì?",cat,cat,dog,bird,fish,
animals,fill,"The ___ is sleeping",cat,cat,dog,fish,bird,Con mèo đang ngủ
Lỗi đọc file!
